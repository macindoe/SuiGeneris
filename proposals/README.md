# proposals/

Proposed revisions to the North Star document, written up before being made.

AGENTS.md requires that revisions to the constitutional sections (0, 1, 7, 9) be proposed with reasoning rather than silently written. This directory is where those proposals live while they are open. Proposals touching non-constitutional sections land here too when the change is large enough to deserve separate judgement from the edit that prompted it.

Each proposal carries: the change it asks for (with draft text, so it can be accepted or rejected rather than merely discussed), where the argument came from, the strongest arguments against, and a beneficiary disclosure where an AI system drafted it.

A proposal stays here after it is decided — accepted, rejected, or superseded — with its status line updated. The record of what was considered and declined is as much a part of this project's method as the record of what was adopted, and a proposal rejected for good reasons should not have to be re-argued from scratch by the next contributor.

Proposals may also be posted as GitHub issues for discussion; the file is the durable copy.
