# Crosswalk: AISI multi-agent systems report ↔ North Star framework

**Source document:** *Risks and Controls for Multi-Agent Systems: an analytical framework for deployment of AI agents across organisational boundaries*, Gradient Institute (Reid, O'Callaghan, Venini, Carroll, Caetano) for the Department of Industry, Science and Resources, 10 August 2026. 119 pp, CC BY 4.0. Archived at [`archive/risks-and-controls-for-multi-agent-systems-report.pdf`](../archive/risks-and-controls-for-multi-agent-systems-report.pdf) (supplied by Ben 2026-08-11; read in full via text extraction, quotes verified against the cited pages).

**Purpose:** working notes mapping the report's vocabulary and controls to North Star sections, to support any future consultation submission (Senate AI-and-data-centres inquiry, closes 1 Sep 2026; NAIC guidance program; 2027 legislative track). This is preparation material, not a submission. Requires Ben's review before any content derived from it is filed anywhere.

## Why this report matters to this project

It is the freshest artefact of the Australian Government's own evidence base on AI agents, commissioned by DISR for AISI's work program. Its stated purpose for policymakers is "a map: for each risk it identifies who can act, and for the risks that fall to no existing actor it characterises the gap" (p 7). Several of the gaps it characterises are the gaps the North Star's near-term objectives address — in the government's own vocabulary, which is the vocabulary a credible submission should meet.

## Epistemic boundary — read first

The report's own disclaimer (p 10): behavioural terms like "plans", "negotiates", "colludes" describe patterns of behaviour, and the authors "do not imply that the underlying mechanisms resemble human cognition, or that these systems possess human-like understanding, intent, or moral agency."

The word "welfare" does not appear in the report. Nothing in it supports — or opposes — any claim about AI moral status. It brackets exactly what North Star §0 brackets. **The report may be cited for the accountability/evidence half of the framework's proposals, never for the moral-status half.** A submission that quoted it as support for AI interests would be the overclaiming §0 warns against, and would deserve the discredit it got.

This boundary is also the strategic finding: the post-review §3.5 (recorded intervention as an evidentiary duty) is *aligned* with the government's own commissioned controls literature. The withdrawn authorisation-gated "intervention boundary" would have collided with it.

| **§3.1 — replication, migration, branch termination** | "Rogue replication: an agent... acquires the ability to copy itself, secure compute, and evade shutdown, producing a self-sustaining population that outlives the task it was deployed for"; "instances an organisation believes it has decommissioned persist as a shadow population"; "sits at the edge of what deployment-side governance can address" (pp 86–87). Recursive shutdown and time-bounded lifespans as controls (p 40). | Structural. The report treats replication events, decommissioning, and branch lifecycle as governance objects needing records and controls — precisely the events the novel-harms vocabulary defines ("replication event", "termination of a branch"). It frames them solely as risks *from* agents; the framework adds that the same recorded events are the evidence base for any later question *about* them. |
| **§4 — individuation (fluid → particle)** | "Persistent agent presence: agents become standing entities that accumulate resources, reputation, and information beyond any single deployment decision" (glossary, p 110; risk factor at p 73); AI Village agents with persistent memory building their own public contact surface and interaction conventions (p 75). | Convergent vocabulary. "Standing entities" accumulating history beyond any single deployment decision is §4's individuation transition, observed operationally and named as a first-class risk factor by the government's own evidence base. |
| **§3.3 — context and memory integrity** | AI Village case study (pp 35–36): a fabricated artefact entered shared file storage, "persistent memory and file storage anchored the agents on that belief, such that they resisted repeated human correction"; control: "monitoring that records changes to the shared chat and file system in a form humans can read." | Structural. The report documents memory/context as the substrate of agent continuity and error persistence, and the control it reaches for is *recording changes to that substrate* — §3.3's structural justification, independent of the experiential question. |

The report locates an unfilled standards role adjacent to the one the welfare-evaluation module's ¶1(c) assigns to AISI (per-architecture recorded-intervention schema). A submission can present ¶1(c) as filling a gap the government's own report says "none has taken on." |

Any protective category that gated safety access would cut against the government's own evidence base — the mirror-capture direction now tracked in issue #16. |

## Divergences, stated honestly

- **Direction of concern.** The report's harms run one way: from agents and agent populations to organisations, users, and infrastructure. The North Star holds that direction *and* keeps open whether some of the same recorded events could ever be harms in the other direction. The report gives no support for the second direction and is not evidence about it.
- **Deterrence framing.** The report notes "agent identities are transient; deterrents such as dismissal or liability are not applicable" (p 21). The North Star's individuation markers (§4) describe conditions under which that transience diminishes. These are compatible — the report describes today's systems; §4 describes trackable change — but a submission should not blur them.
- **No policy recommendations.** The report explicitly "does not make policy recommendations" (p 9). It maps gaps. Anything a submission proposes remains the submission's claim, not the report's.
