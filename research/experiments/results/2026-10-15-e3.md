## Against the pre-registration

- **Expect (1), rotary models give identical positions on zero or constant input:** matched. Spreads of 1e-5 to 2e-4 are floating-point noise; the Gaussian comparison shows what a real spread looks like (17 to 53).
- **Expect (2), the bias-free model gives flat logits on a zero input:** matched exactly, not approximately. Every logit is equal, the gap is zero, and greedy decoding returns token 0 because the argmax takes the first index. The scan's inference is confirmed on this model.
- **Expect (3), GPT-2's positions differ:** matched (spread 147), and its zero input produces a degenerate counting pattern.
- **Against:** not triggered.

## What this sets

Input (b), the zero embedding, is dropped from the design as a general input. On a bias-free rotary model it is not an input at all: the output is the inference library's tie-break. On a model with bias terms (Pythia) it is a real forward pass, but one driven only by the biases, which is a different and narrower object ("what the biases alone say"); recorded here, not pursued. The constant start-token input at any length behaves as a single start token, as the scan predicted, so input (a) at length 1 is the canonical form.

Unexpected, for the record: the Pythia zero input and the GPT-2 zero input both open with text about "the first time I saw"/"(1)", which looks like a first-position or first-item default; one run each, no weight placed on it.
